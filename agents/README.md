# 🤖 Агенты для генерации видео

Это набор ИИ-агентов, каждый из которых — **профессионал в своей роли**.
Они работают как конвейер: результат одного передаётся следующему.

```
💡 Идея  →  🎬 Сценарист  →  🎨 Художник  →  🎞️ Аниматор  →  🎥 Видео
```

## Что такое «агент» здесь

Агент — это **не отдельная нейросеть, которую надо обучать**.
Это уже готовая ИИ-модель (например, Claude или GPT), которой дали:

1. **Роль** — кто он («ты профессиональный художник по промптам»).
2. **Инструкцию** — что и как делать.
3. **Формат ввода/вывода** — что он получает и что отдаёт.
4. **Примеры** — образцы хорошей работы.

Всё это лежит в папке агента в файле `agent.md`.

## Список агентов

| Папка | Агент | Что делает | Что получает на вход | Что отдаёт |
|-------|-------|-----------|----------------------|-----------|
| [`scenarist/`](./scenarist/) | 🎬 Сценарист | Превращает идею в сценарий и раскадровку | Идея / тема | Сцены + описания кадров |
| [`hudozhnik/`](./hudozhnik/) | 🎨 Художник | Пишет идеальные промпты для картинок | Описание кадра | Готовый image-промпт |
| [`animator/`](./animator/) | 🎞️ Аниматор | Пишет промпты для оживления картинок | Кадр + картинка | Готовый video/motion-промпт |

## Структура одной папки агента

```
hudozhnik/
├── agent.md       ← роль и инструкция («мозг» агента) — главный файл
├── config.json    ← настройки для подключения к сайту (название, вход, выход, кто следующий)
└── examples.md    ← примеры «вход → выход» для обучения качеству
```

## Как это подключить к сайту (позже)

Когда дойдёшь до интеграции:

1. Берёшь текст из `agent.md` → кладёшь как **системный промпт** для модели.
2. Поля из `config.json` (`input`, `output`, `next`) подсказывают, как связать
   агентов в цепочку: выход Сценариста → вход Художника → выход Художника → вход Аниматора.
3. На сайте пользователь пишет идею → конвейер прогоняет её через всех троих →
   на выходе готовые промпты (или сразу видео, если подключишь генератор).

> Сейчас агенты — это **инструкции**. Им не нужен код, чтобы существовать.
> Код понадобится только на этапе подключения к сайту.
