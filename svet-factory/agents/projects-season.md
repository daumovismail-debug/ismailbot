# 📁 ПРОЕКТЫ + АРКА СЕЗОНА — как устроено

> Проект = сериал в одном месте: бриф, каста, серии, сквозная загадка сезона.
> Внутри проекта легко догенерить «2 серию», вести арку, удалить всё.

## Что такое Проект
Именованный контейнер (напр. «Люстра или развод»). Хранит:
- **бриф** (от Режиссёра): тон, герой, конфликт;
- **касту** (персонажи + эталоны) — общая на весь сериал;
- **арку сезона** (сквозная загадка);
- **серии** (эпизоды) со статусом и артефактами;
- настройки (палитра, язык, голоса).

## Операции (для интерфейса)
- **Создать / назвать** проект.
- **Список** проектов и серий внутри.
- **Догенерить серию N** (продолжение): переиспользует касту + арку, помнит, чем
  кончилась прошлая серия (клиффхэнгер → завязка следующей).
- **Дублировать** серию (как шаблон) / **переснять** кадр.
- **Удалить** серию или **весь проект** (со всеми артефактами).

## 🧵 Арка сезона (season bible)
Чтобы зритель смотрел сериал, а не разрозненные ролики:
- **Центральная загадка/цель сезона** (напр. «спасут ли брак?»).
- **Сквозные нити** (тайна чека, свекровь, развод) — тянутся через серии.
- **План эскалации:** каждая серия поднимает ставки + свой мини-клиффхэнгер,
  ведущий к следующей; финал сезона — большой payoff.
- **Каденция откровений 3-7-21** (из Сценариста): крупные повороты по нарастающей.
Сценарист ОБЯЗАН: каждая серия двигает арку и кончается крючком на следующую.

## Структура хранения (на диске)
```
projects/<project_id>/
  project.json        // бриф, арка, настройки
  cast/               // эталоны персонажей (модельные листы)
  episodes/<n>/
    episode.json      // объект серии (по orchestration.md)
    shots/            // картинки/клипы/аудио кадров
    final.mp4         // готовый ролик
    metrics.json      // данные из соцсети (фаза 2)
```

## Модель проекта (JSON)
```json
{
  "id":"lyustra_razvod",
  "name":"Люстра или развод",
  "brief": {"tone":"драма","hero":"heroine","core_conflict":"люстра vs муж"},
  "season_arc": {
    "central_question":"Сохранят ли брак из-за люстры?",
    "threads":["тайна чека мужа","свекровь","угроза развода"],
    "escalation":["ультиматум","измена?","развод","примирение/разрыв"]
  },
  "cast_ref":"project-bible.md",
  "episodes":[{"n":1,"status":"done","cliffhanger":"кому он звонит?"}]
}
```

## Связь с командой
- **Режиссёр** заводит проект + арку. **Сценарист** пишет серии по арке.
- **Кастинг** ведёт касту проекта. Остальные работают внутри серии.
- **Аналитик** смотрит, какие серии/нити держат аудиторию → корректируем арку.
