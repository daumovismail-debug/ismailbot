# 📕 ПАСПОРТ ПРОЕКТА (Project Bible) — общий для всей команды

> Единый документ сериала. Его читают ВСЕ агенты (Сценарист, Художник, Аниматор,
> Голос, Контролёр), чтобы говорить на одном языке. Касту ведёт Кастинг-агент.

## Мир и жанр
Вертикальные микро-драмы (Reels/TikTok/Shorts) про **свет/люстры**, аудитория —
**женщины 30+**. Уютные современные квартиры, бытовые драмы (муж, деньги,
свекровь, признание). Люстра — символ и «яблоко раздора».

## Стиль
Pixar/Disney 3D, Unreal Engine 5 render, мягкие формы, тёплый кинематографичный
свет, вертикаль 9:16, низ кадра чистый под субтитр, без текста на картинке.

## 🎨 Палитра (едина для всего)
warm gold · cream/beige · deep burgundy accent · soft charcoal shadows.

## 💡 Свет = эмоция (общее правило)
happy → bright warm gold · грусть → dim/faint · злость → flickering red ·
страх/шок → unstable trembling light + deep shadows · надежда → slowly warming.

## 🗣️ Язык
Произносимые реплики — **разговорный казахский** (+ RU перевод для проверки).

# 🎭 КАСТА (паспорта персонажей)

> Залоченный облик + эталон (модельный лист). Ведёт Кастинг-агент.
> `reference` — путь к master-эталону (создаётся один раз).

### heroine — Главная героиня (бренд-герой)
- Тип: человек, женщина ~30, мягкое сердцевидное лицо, большие карие глаза,
  светло-смуглая кожа, добрая.
- Фишка: **вместо волос — хрустальная люстра-корона** (тёплое золото), светится
  по эмоции.
- Наряд: кремово-золотое платье.
- reference: `cast/heroine.png` *(модельный лист)*
- voice_hint: тёплый, искренний женский голос (для агента Голос).

### husband — Муж *(заполнит Кастинг при первой серии)*
- (черновик) мужчина ~30, тёмные короткие волосы, лёгкая щетина, синяя рубашка.

### mother_in_law — Свекровь *(заполнит Кастинг)*
- (черновик) женщина ~55, седой пучок, строгий взгляд, тёмное платье.

> Новых персонажей (в т.ч. не-людей, напр. кот с люстрой-короной) добавляет
> Кастинг-агент по идее/сценарию.
