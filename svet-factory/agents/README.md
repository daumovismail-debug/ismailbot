# 🧠 Агенты-профи (редактируемые инструкции)

Здесь живут «должностные инструкции» агентов команды. Это и есть их «обучение»:
правишь файл — меняется поведение агента. Чем больше эталонных примеров внизу
каждого файла, тем профессиональнее агент.

| Файл | Агент | Статус |
|------|-------|--------|
| `scenarist.md` | 🎬 Сценарист | в работе (обучаем первым) |
| `artist.md` | 🎨 Художник | ✅ подготовлен |
| `animator.md` | 🎬 Аниматор | дальше по плану |
| `voice.md` | 🎙️ Голос | дальше по плану |
| `controller.md` | 🛡️ Контролёр | дальше по плану |

## Как «обучать» агента
1. Уточняешь его роль и стандарты (верх файла).
2. Добавляешь эталонные примеры «вот так 🔥» и «так НЕ надо».
3. Прогон → оценка по чек-листу → лучшее добавляем в примеры, провалы → в правила.
4. Повторяем — агент стабильно растёт до профи и выше.

> Подключение этих файлов к конвейеру (чтобы модули читали инструкции отсюда)
> делаем отдельным шагом, когда инструкции будут готовы.
