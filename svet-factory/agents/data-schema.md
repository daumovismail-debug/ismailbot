# 🗂️ СХЕМА ДАННЫХ — журнал экспериментов (основа обучения)

> Одна строка = один опубликованный ролик. Это «топливо» для Аналитика: по этим
> данным команда учится (что заходит). Заполняется в 2 фазы: до публикации
> (Издатель) и после (метрики из соцсетей).

## Где хранить (бесплатно)
- **Основное:** файл `data/experiments.csv` (или `.json`) в проекте — бесплатно,
  просто, Аналитик читает/пишет напрямую.
- **Опционально (зеркало):** бесплатный Google Sheet или Notion — удобно смотреть глазами.
- Видео-файлы — в Telegram (хранилище); тут только **данные и ссылки**.

## Поля записи

### Фаза 1 — при создании/публикации (Издатель)
| Поле | Что |
|------|-----|
| `id` | уникальный id ролика (ep_001_s1) |
| `project` / `episode` | проект и номер серии |
| `theme` | тема/идея |
| `hook_type` | тип хука (ультиматум/шок-находка/…) |
| `hook_text` | первая фраза (cold open) |
| `length_sec` | длина ролика |
| `characters` | кто в кадре (id из касты) |
| `platform` | tiktok / reels / shorts |
| `post_url` / `post_id` | ссылка/ID поста (нужно Аналитику!) |
| `post_time` | дата-время публикации |
| `caption` / `hashtags` / `cover` | подпись, теги, обложка |
| `ab_variant` | вариант A/B (если тестируем) |

### Фаза 2 — после публикации (метрики из соцсети)
| Поле | Что | Цель/порог |
|------|-----|-----------|
| `views` | просмотры | — |
| `intro_retention` | % досмотревших 3 сек | ≥70% |
| `completion` | % досмотра до конца | ≥70% (по длине) |
| `avg_watch_sec` | среднее время просмотра | — |
| `shares` | репосты | выше = лучше |
| `saves` | сохранения | — |
| `comments` | комментарии | осмысленные ценнее |
| `rewatch` | повторные просмотры/луп | приоритетный сигнал |
| `follows` | подписки с ролика | — |
| `verdict` | вывод Аналитика | — |
| `learnings` | что забрали в примеры агентов | — |

## Пример (CSV-заголовок)
```
id,project,episode,theme,hook_type,hook_text,length_sec,characters,platform,post_id,post_time,caption,hashtags,cover,ab_variant,views,intro_retention,completion,avg_watch_sec,shares,saves,comments,rewatch,follows,verdict,learnings
```

## Как это замыкает обучение (цикл)
1. **Издатель** пишет строку (фаза 1) + `post_id`.
2. После публикации метрики (фаза 2) вносятся (сначала **вручную** из TikTok/Insta
   Studio — бесплатно; позже можно полуавтомат).
3. **Аналитик** читает журнал → ставит `verdict` → выносит `learnings` в банки
   примеров нужных агентов (Сценарист, Художник…).
4. Команда умнеет на РЕАЛЬНЫХ данных — это и есть Этап H.

⚠️ Без `post_id` и без внесения метрик журнал пустой → обучения на данных нет.
