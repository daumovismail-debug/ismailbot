# 🏭 СВЕТ — фабрика коротких видео

Автоматический сервис-конвейер: вводишь тему → сервис сам пишет сценарий,
генерит картинки (Nano Banana Pro), оживляет их в видео (Veo 3.1),
озвучивает (ElevenLabs) и склеивает готовый вертикальный ролик.

Ниша по умолчанию: люстры/свет, аудитория — женщины 30+.
Герой — Pixar-девушка с хрустальной люстрой-короной, чей свет = её эмоции.

## 8 модулей конвейера

| # | Модуль | Что делает | Инструмент |
|---|--------|-----------|------------|
| 1 | `ИДЕЯ` | выбирает тему-драму | банк идей |
| 2 | `СЦЕНАРИЙ` | 5 сцен по формуле + реплики | ChatGPT |
| 3 | `РАСКАДРОВКА` | 🎨 Агент-Художник + 🎬 Агент-Аниматор пишут промпты | ChatGPT |
| 4 | `ГЕРОЙ` | эталонный кадр героини | ChatGPT (gpt-image-1) |
| 5 | `КАРТИНКИ` | 5 кадров по промптам Агента-Художника | ChatGPT (gpt-image-1) |
| 6 | `АНИМАЦИЯ` | оживляет кадры по промптам Агента-Аниматора | Grok Imagine |
| 7 | `ЗВУК` | озвучка реплик | ElevenLabs |
| 8 | `МОНТАЖ` | склейка + субтитры → финал | ffmpeg |

## Два агента-профи по промптам

- 🎨 **Агент-Художник** (`backend/agents.py`) — пишет промпты для картинок (ChatGPT).
- 🎬 **Агент-Аниматор** — пишет промпты движения для оживления (Grok Imagine).

С ключом OpenAI агенты «думают» через LLM под каждую сцену; без ключа — работают
на профессиональных шаблонах (демо-режим).

## Быстрый старт

```bash
cd svet-factory
pip install -r requirements.txt
cp .env.example .env        # вставь свои API-ключи (или оставь пустыми для демо)
./run.sh                    # откроется на http://localhost:8000
```

Без ключей сервис работает в **демо-режиме** (плейсхолдеры) — чтобы увидеть
весь конвейер end-to-end. С ключами — выдаёт настоящий контент.

## Переменные окружения

| Переменная | Зачем | Обязательна |
|-----------|-------|-------------|
| `OPENAI_API_KEY` | сценарий + агенты + картинки (gpt-image-1) | для картинок |
| `XAI_API_KEY` | анимация (Grok Imagine) | для видео |
| `ELEVENLABS_API_KEY` | озвучка | для голоса |
| `PUBLIC_BASE_URL` | публичный адрес сервиса (Grok скачивает кадры по URL) | для анимации |
| `OPENAI_TEXT_MODEL` | модель текста (по умолч. `gpt-4o-mini`) | нет |
| `OPENAI_IMAGE_MODEL` | модель картинок (`gpt-image-1`) | нет |
| `XAI_VIDEO_MODEL` | модель видео (`grok-imagine-video`) | нет |
| `ELEVENLABS_VOICE_ID` | id голоса | нет |

> ⚠️ `PUBLIC_BASE_URL` обязателен для анимации: Grok Imagine забирает кадры по
> ссылке, поэтому сервис должен быть доступен из интернета по этому адресу.

## Архитектура

- `backend/main.py` — FastAPI: API + раздача веб-панели
- `backend/pipeline.py` — оркестратор, гоняет модули по очереди
- `backend/modules/` — 8 модулей конвейера
- `backend/integrations/` — обёртки над Gemini и ElevenLabs
- `backend/ffmpeg_tool.py` — генерация клипов и финальная склейка
- `web/` — веб-панель (вводишь тему, видишь прогресс, качаешь ролик)
