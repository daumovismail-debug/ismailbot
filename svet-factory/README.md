# 🏭 СВЕТ — фабрика коротких видео

Автоматический конвейер: вводишь тему → команда AI-агентов сама пишет
микро-драму (сценарий на казахском + RU-перевод), рисует кадры, оживляет их,
озвучивает, монтирует и собирает готовый вертикальный ролик 9:16, ~45–60 сек.

Ниша по умолчанию: люстры/свет, аудитория — женщины 30+.
Герой — Pixar-девушка с хрустальной люстрой-короной, чей свет = её эмоции.

## 12 модулей конвейера

| # | Модуль | Что делает |
|---|--------|-----------|
| 1 | `ИДЕЯ` | тема-драма + бриф Режиссёра (тон, хук, эмоция-цель) |
| 2 | `СЦЕНАРИЙ` | микро-драма 10–14 кадров (cold open → клиффхэнгер), реплики KZ+RU |
| 3 | `РАСКАДРОВКА` | Художник: image_prompt (Style Bible + свет=эмоция) + motion_prompt |
| 4 | `ГЕРОЙ` | Кастинг: паспорт + эталон героини + модельный лист (кэш, лок лица) |
| 5 | `КАРТИНКИ` | кадры по промптам + QC лица (cosine ≥0.60, выбор лучшего, до 3 попыток) |
| 6 | `АНИМАЦИЯ` | оживляет кадры (Grok) или плавный зум Ken Burns |
| 7 | `ЗВУК` | план озвучки KZ + синтез (если подключён движок) |
| 8 | `МОНТАЖ` | склейка + karaoke-субтитры (слово-в-слово) → финальный ролик |
| 9 | `КОНТРОЛЬ` | проверка кадров/лица/длины (vision через подписку) |
| 10 | `ПРИЁМКА` | вайб-ревью Режиссёра: хук/эмоция/клиффхэнгер → принято/на доработку |
| 11 | `АНАЛИТИК` | прогноз силы хука |
| 12 | `ПУБЛИКАЦИЯ` | пакет публикации + выгрузка в Telegram-архив |

## Движки (всё бесплатно)

- **Текст** (сценарии, агенты) — через **OpenClaw** под твоей подпиской ChatGPT
  (`openclaw` на сервере) → бесплатно. Картинки OpenClaw НЕ умеет (только текст).
- **Картинки** (кадры, эталоны) — **Pollinations.ai**: бесплатно, без ключей и
  регистрации. Это основной «художник». Запасной путь — OpenAI API по ключу.
- **Видео** — Grok Imagine. По умолчанию ВЫКЛ → анимация = Ken Burns (плавный
  зум). Можно включить настоящее видео через ТВОЮ подписку Grok (без API-ключа,
  автоматизация браузера) — см. ниже.
- **Казахский голос** — ElevenLabs/клон (на тест).
- **Сборка** — ffmpeg (бандл imageio-ffmpeg, без системной установки).

**Без ключей и без OpenClaw всё работает в демо-режиме** (плейсхолдеры) —
чтобы увидеть весь конвейер end-to-end и собрать ролик.

## Быстрый старт

```bash
cd svet-factory
pip3 install -r requirements.txt --break-system-packages   # Ubuntu 23+: нужен флаг
cp .env.example .env        # ключи можно оставить пустыми для демо
./run.sh                    # откроется на http://<сервер>:8000
```

Открой `http://<адрес-сервера>:8000`, введи тему, нажми «Запустить» — увидишь,
как идут все 11 модулей, и в модуле МОНТАЖ скачаешь готовый ролик.

## Реальный режим (на сервере, под подпиской)

1. Установи и залогинь OpenClaw: `openclaw onboard` (вход через ChatGPT).
2. В `.env`: оставь `USE_OPENCLAW=1` (по умолчанию). Картинки/текст пойдут бесплатно.
3. Видео Grok — включается `USE_OPENCLAW_VIDEO=1` ТОЛЬКО когда проверишь, что
   движок отвечает (иначе долго висит; есть защита `ANIMATE_BUDGET_SEC`).
4. Казахский голос — `ELEVENLABS_API_KEY` (или клон).
5. Telegram-архив — `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID`.

## Grok-видео через ПОДПИСКУ (без API-ключа)

Настоящее «оживление» кадров через твою подписку Grok (не платный API). Это
автоматизация браузера grok.com под твоим логином.

> ⚠️ Требует много памяти (Chromium тяжёлый) и хрупко к смене вёрстки
> grok.com. На сервере 1 ГБ работает ТОЛЬКО со swap-подкачкой (медленнее).

Всё делается в терминале сервера тремя шагами:

1. Подготовить сервер (swap + браузер) — один скрипт:
   ```bash
   sudo bash svet-factory/tools/setup_grok.sh
   ```
2. Отдать серверу свою сессию grok.com (один раз):
   - войди на grok.com в обычном браузере, поставь расширение «Cookie-Editor»;
   - на вкладке grok.com: Cookie-Editor → Export → «Export as JSON»;
   - вставь в файл `cookies.json` на сервере и импортируй:
   ```bash
   python3 svet-factory/tools/grok_import_cookies.py cookies.json
   ```
3. Включить и перезапустить:
   ```bash
   echo "USE_GROK_BROWSER=1" >> svet-factory/.env
   ```
   затем перезапусти сервис.

Если grok.com поменял вёрстку и видео не берётся — поправь селекторы
`GROK_SEL_PROMPT` / `GROK_SEL_SUBMIT` в `.env`; при сбое модуль кладёт скриншот
`grok_debug.png` в папку серии — по нему видно, что нажимать. Сбой автоматизации
не ломает ролик — кадр уходит на Ken Burns.

## Ключевые переменные `.env`

| Переменная | Зачем | Обязательна |
|-----------|-------|-------------|
| `USE_OPENCLAW` | картинки/текст через подписку (по умолч. вкл) | — |
| `USE_OPENCLAW_VIDEO` | видео через OpenClaw/Grok (по умолч. ВЫКЛ) | для видео |
| `ANIMATE_BUDGET_SEC` | лимит времени на анимацию серии (480с) — защита от зависания | — |
| `OPENAI_API_KEY` | запасной путь для текста/картинок | нет |
| `XAI_API_KEY` + `PUBLIC_BASE_URL` | анимация через Grok API по URL кадра | для видео |
| `ELEVENLABS_API_KEY` / `_VOICE_ID` | озвучка | для голоса |
| `TELEGRAM_BOT_TOKEN` / `_CHAT_ID` | выгрузка готовых роликов | для архива |

## Архитектура

- `backend/main.py` — FastAPI: API + раздача веб-панели
- `backend/pipeline.py` — оркестратор, гоняет 11 модулей по очереди + гейты
- `backend/modules/` — 11 модулей конвейера
- `backend/agent_runner.py` — исполняет рецепты агентов (`agents/*.md`) через LLM
- `backend/integrations/` — OpenClaw, OpenAI, xAI(Grok), ElevenLabs, Telegram
- `backend/ffmpeg_tool.py` — клипы и финальная склейка
- `agents/*.md` — редактируемые «должностные» рецепты агентов (чертёж команды)
- `web/` — веб-панель (тема → прогресс → скачать ролик)
